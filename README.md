# 身体からの便り用効果音パッド

劇の本番用に、ワンタップで効果音を鳴らすためのページ。PC と iPad で使う想定である。

## 機能

- 3×3 の 9 ボタン。タップした瞬間に再生する
- 再生中の同じボタンをもう一度押すと、最初から再生し直す
- 別のボタンは重ねて鳴らせる
- 全停止ボタン（PC は Esc キーでも可）
- ボタンごとの音量スライダー（0〜150%）。設定はブラウザに保存される
- PC はキーボードの 1〜9 でも再生できる
- 再生中は進行バーと残り時間を表示する
- 本番中に画面がスリープしにくくする（対応ブラウザのみ）

## 音源の入れ方

1. 音源を `sounds` フォルダに `01.mp3` 〜 `09.mp3` という名前で入れる
2. `index.html` の上の方にある `SOUNDS` を開き、ボタン名を書き換える

```js
const SOUNDS = [
  { name: "雷", file: "sounds/01.mp3" },
  { name: "ドアのノック", file: "sounds/02.wav" }, // wav や m4a でも可。拡張子を合わせる
  ...
];
```

音源が入っていないボタンは「音源なし」と表示され、押しても鳴らない。

## 手元での確認

`index.html` をダブルクリックで開くだけでも、PC の Chrome / Edge で確認できる（ローカル確認モード。音量は 100% が上限になる）。

本番と同じ動きで確認したい場合は、`sfx-pad` フォルダでコマンドプロンプトを開き、次を実行して `http://localhost:8000` を開く。

```
py -m http.server 8000
```

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`sfx-pad`、Public）
2. このフォルダの中身（`index.html`、`README.md`、`sounds` フォルダ）をアップロードする
3. リポジトリの Settings → Pages を開き、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
4. 数分後に `https://ユーザー名.github.io/sfx-pad/` で開けるようになる

## 本番前のチェック

- 最初に画面をタップすると開始できる（ブラウザの仕様上、一度タップするまで音が出ない）
- iPad は Safari で開き、共有ボタン →「ホーム画面に追加」しておくと全画面で使える
- iPad の本体音量と、消音になっていないかを確認する
- 会場の Wi-Fi が不安な場合も、一度ページを開いて読み込みが「9/9 読み込み完了」になれば、その後は通信なしで鳴らせる（ページを再読み込みしない限り）
